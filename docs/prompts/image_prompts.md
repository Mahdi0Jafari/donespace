# پرامپت‌های طلایی برای ساخت عکس‌های وبلاگ (DoneSpace)

از آنجایی که عکس‌های سه‌بعدی (3D Isometric) سبک و رنگ‌بندی بسیار هماهنگی با دیزاین سیستم سایت دارند، پرامپت‌هایی که برای ساختشان استفاده شد را اینجا ذخیره کردم.
شما می‌توانید برای مقالات بعدی، فقط موضوع عکس (مثلا اتاق خواب یا گوشی موبایل) را تغییر دهید و بقیه پرامپت را ثابت نگه دارید تا تمام عکس‌های وبلاگ یک‌دست و حرفه‌ای بمانند.

## پرامپت مقاله تقسیم کار (تصویر اتاق نشیمن)
```text
A premium 3D isometric illustration of a minimal, aesthetic living room. Above the sofa floats a sleek, glassmorphism UI dashboard showing a checklist. The color palette must strictly follow the brand colors: bright white background, soft purple (#8c52ff) accents, and subtle yellow (#fde047) highlights. Clean lines, modern SaaS blog aesthetic, no humans, highly professional, 8k resolution.
```
